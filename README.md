# T5QuantLab Open Source

Public examples and technical notes for MT4/MT5 tool development.

T5QuantLab builds verifiable trading-tool engineering and delivery workflows for MetaTrader users and developers. This repository contains only original public examples, sanitized demonstrations, and educational documentation.

## Contents

- `docs/` — installation, debugging, and development notes.
- `examples/mt5-indicator-display-demo/` — a minimal MT5 indicator display example.
- `examples/journal-debugging-demo/` — a safe Journal logging example.
- `samples/sanitized-chart-data/` — placeholder-free, non-customer sample data.

## Scope boundary

This repository does not contain paid EA source code, commercial indicator algorithms, membership, payment, authorization, download, customer, production, or cloud-compiler systems. Commercial products and services are described separately at [t5quantlab.com](https://t5quantlab.com).

Examples are educational and do not provide trading advice, performance claims, or live-trading guarantees.
