# MT4/MT5 installation checklist

1. Open the data folder from the terminal you will actually use.
2. Place an MT4 indicator under `MQL4/Indicators` or an MT5 indicator under `MQL5/Indicators`.
3. Compile the source in the matching MetaEditor when source compilation is part of the example.
4. Refresh the Navigator and confirm the chart symbol and timeframe.
5. Read `Experts` and `Journal` before changing parameters.

The terminal, platform version, file location, dependencies, and timeframe must be checked together. A successful compilation alone does not prove runtime compatibility or trading performance.
